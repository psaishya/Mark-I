# Mark I: Virtual Canvas Using Hand Gestures

## Overview
"Mark I" is an innovative project that leverages computer vision technology to create a virtual canvas in the air. Users can draw and paint simply by waving their hands, making it an engaging and interactive tool for digital content creation. This project aims to enhance online collaboration and creativity by providing a natural and intuitive interface for users to interact with digital content.

## Features
- **Hand Tracking**: Real-time detection and tracking of hand movements using OpenCV.
- **Gesture Recognition**: Recognize and interpret hand gestures for drawing, erasing, and selecting tools.
- **Virtual Canvas**: Draw freehand lines, shapes, and use various tools without physical contact.
- **Customization**: Choose different colors, adjust thickness, and switch between drawing modes.
- **User-Friendly Interface**: Intuitive UI for selecting tools and adjusting parameters.

## Usage
- **Hand Detection**: Point your hand towards the webcam to start drawing.
- **Gesture Recognition**: Use specific hand gestures to select tools and adjust parameters.
- **Drawing**: Draw freehand lines, shapes, and use the eraser tool.
- **Customization**: Adjust colors, thickness, and other settings using the provided UI.
